# Changelog

All notable changes to DuhzitOS will be documented in this file.

## [0.0.1] - 2024-03-30

### Added
- Initial release of DuhzitOS
- Forked from ZaneyOS with complete rebranding
- Maintained core functionality and modular structure
- Updated documentation and configuration files
- Set up new versioning scheme

### Features
- Hyprland window manager configuration
- Stylix theming system
- Multiple hardware profiles (AMD, NVIDIA, Intel, VM)
- Home Manager integration
- Modular configuration structure

### Technical Details
- Based on NixOS 23.11
- Uses flakes for configuration management
- Implements atomic builds for system changes
- Supports multiple hardware configurations
- Includes comprehensive documentation
